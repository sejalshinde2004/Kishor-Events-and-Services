# Kishor Events and Services

## Project Overview
A web-based event management system developed using PHP and MySQL.

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Features
- User Registration & Login
- Event Booking
- Payment Verification
- Admin Dashboard
- Reports Generation
- Gallery Management
- Organizer Management
- Feedback System

## How to Run

1. Install XAMPP
2. Start Apache and MySQL
3. Import the database into phpMyAdmin
4. Copy project folder into htdocs
5. Open localhost/Kishor-Events-and-Services
